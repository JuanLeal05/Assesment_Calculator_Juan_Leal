# Sezzle Asssesment
**Created by:** Juan Carlos Leal Cruz

## Objective
Create a ful-stack calculator application that has a working frontend built using `React` + `Typescript` that consumes a backend API built using `Python` with **FastAPI**.

## Backend API
The whole API works under he prefix `api/v1/calculate` and starting there, the endpoints exposed are:
- **`/add`:** Used for the operation of adding two numbers.
- **`/subtract`:** Used for the operation of substracting two numbers.
- **`/multiply`:** Used for multiplying two numbers.
- **`/divide`:** Used for diving two numbers.
- **`/squareRoot`:** Used to find the square root of a number.
- **`/power`:** Used to raise a number to a power.
- **`/percent`:** Used to find the percentage of a number.
